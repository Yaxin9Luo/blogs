## What This Direction Is About

My current definition is:

> Build an executable, observable, verifiable, and iterative harness for complex multimodal tasks, so coding agents or design agents can improve through grounded feedback instead of relying on one-shot prompting.

The main task shapes are:

- **paper2any**: converting papers into posters, slides, web pages, reports, or video scenes.
- **artifact-producing agents**: producing HTML, PPT, PDF, charts, design artifacts, or runnable pages rather than chat answers.
- **long-horizon workflows**: document ingestion, content planning, asset selection, layout generation, rendering, visual critique, and repair loops.
- **verification and benchmarks**: comparing systems while also checking whether a single artifact is deliverable, editable, and reusable.
- **human-in-the-loop iteration**: humans provide preferences, references, and quality judgments; agents turn those signals into evaluators, contracts, and regression loops.
