## 这个方向要回答什么

我把这个方向先定义成一句话：

> 给复杂多模态任务搭一个可执行、可观测、可验证、可迭代的 harness，让 coding agent 或 design agent 能在里面持续改进，而不是只靠一次 prompt 赌结果。

目前最关心的任务形态包括：

- **paper2any**：从论文生成 poster、slides、web page、report、video scene。
- **artifact-producing agents**：输出不是聊天答案，而是 HTML、PPT、PDF、图表、设计稿、可运行页面。
- **long-horizon workflows**：任务需要文档摄取、内容规划、素材选择、布局生成、渲染验证、视觉 critic、修复循环。
- **verification and benchmark**：不仅比较系统分数，还要判断单个产物是否真的能交付、能编辑、能复用。
- **human-in-the-loop iteration**：人提供偏好、正反例和质量判断，agent 负责把判断沉淀成 evaluator、contract 和 regression loop。
