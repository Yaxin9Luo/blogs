Engineering logs preserve the process behind an implementation, not just the final code.

## Useful Granularity

- One important debugging session
- One system design tradeoff
- One tooling setup process
- One failed technical direction

## Recommended Template

```md
## Background

## Goal

## Constraints

## Implementation

## Pitfalls

## What I Would Change Later
```

The first engineering log can document this site itself: why Astro, Starlight, and MDX were chosen, and why not every page should be hand-written in raw HTML.
