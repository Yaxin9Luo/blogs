2. The poster-generation notes make the problem concrete: academic posters are not promotional graphics. The challenge is content synthesis, information density, visual evidence, editability, and factual accuracy.
3. The verifier and benchmark notes separate deterministic checks, VLM critique, rubrics, reference pools, paper quizzes, and benchmark visualization.
4. The main automatic-iteration route records the shift from manual prompt tuning to coding-agent-driven pipeline improvement based on eval signals.
5. The weekly notes show a key transition: after layout nearly converges, the bottleneck moves to text accuracy, repetition, section-to-panel allocation, and memory.

## Core Research Judgments

### 1. Artifact-first, not agent-first

If the goal is a poster, slide deck, web page, or video, define the artifact contract before writing the agent prompt. The contract should specify content coverage, chart usage, visual density, editable structure, rendering path, and failure conditions.

### 2. Harness is the engineering interface for subjective quality

“The poster does not look good” is not useful enough. “The information architecture lacks a method-to-evidence-to-takeaway path, three panels repeat the same conclusion, and chart references are not tied to source packs” is actionable.

### 3. Benchmark does not replace verification

Benchmarking compares systems. Verification decides whether one artifact is deliverable. Long-horizon multimodal tasks need both.

### 4. Reference pools steer optimization

If references are mostly visual walls or screenshot-heavy posters, the generator may learn that “more image area” means “better.” References should be grouped by artifact archetype: text-heavy synthesis, theory board, benchmark/table-first, GUI/video, and so on.

### 5. Bottlenecks migrate during automatic iteration

Early issues are layout, overlap, and rendering. Later issues become text repetition, factual errors, panel content allocation, source grounding, and metric weighting.
