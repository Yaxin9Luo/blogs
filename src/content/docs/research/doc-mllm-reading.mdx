## 背景

这类论文通常不只是把图片塞进语言模型，而是在处理更难的结构问题：页面有版面、段落、图表、公式、阅读顺序和跨页依赖。阅读时要先判断作者是否真正建模了文档结构，还是只是在视觉编码器外面包了一层语言接口。

<Insight title="阅读时先问的问题">
视觉 token 是否保留了版面关系？文本 token 是否能回到页面坐标？模型输出是否只是回答问题，还是能生成可编辑、可定位、可验证的文档产物？
</Insight>

## 核心问题

- 输入文档被表示成什么：整页图像、裁剪区域、OCR token、layout token，还是混合表示？
- 视觉和文本如何对齐：cross-attention、统一 token 序列、坐标嵌入，还是后处理匹配？
- 训练目标是否覆盖真实任务：理解、抽取、问答、布局恢复、生成、编辑。

## 方法拆解

1. 输入编码：记录图像分辨率、patch 策略、OCR 使用方式和坐标编码。
2. 融合层：记录视觉特征进入语言模型的位置和方式。
3. 输出约束：记录模型是否输出结构化 JSON、HTML、Markdown、坐标或自然语言。
4. 评测设置：记录数据集、指标、失败案例和是否有人工可用性评估。

## 读完后的下一步

- 找一个最小复现任务。
- 把论文方案映射到自己的项目问题。
- 写出至少一个反例或失败场景。
