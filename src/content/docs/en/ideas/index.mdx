## Starter Idea

### Document generation should evaluate editability

- Motivation: Many models can generate documents that look correct, but are expensive to edit.
- Intuition: Editability should be a core metric for document generation systems.
- Minimal experiment: Compare HTML, Markdown, PPTX, and DOCX under the same editing task.
- Why it might be wrong: Users may care only about visual output, not intermediate structure.
